# AI-Powered Customer Feedback Automation

An intelligent customer feedback automation project built with **n8n and Google Gemini**. This workflow helps businesses collect customer feedback, automatically classify it using AI, organize the results, and send notifications.

## 🚀 Project Overview

Managing customer feedback manually can take time and effort. This automation workflow uses AI to simplify the process.

When a customer submits feedback, n8n sends the information to Google Gemini for analysis. The AI classifies the feedback into the appropriate category, and the workflow routes the result to the connected business tools.

## ✨ Key Features

- Automated customer feedback collection
- AI-powered feedback classification
- Automatic complaint identification
- Compliment recognition
- Future feature request detection
- Organized feedback management
- Automated Slack notifications
- Email notifications through Gmail
- Airtable integration for data management

## 🔄 How the Workflow Works

1. **Feedback Submission:** A customer submits feedback through a form.
2. **AI Analysis:** Google Gemini analyzes the submitted feedback.
3. **Classification:** The AI identifies the feedback category.
4. **Workflow Routing:** n8n routes the feedback according to its category.
5. **Data Management:** Feedback is stored in the appropriate Airtable table.
6. **Notifications:** Slack and Gmail send automated notifications.

## 📂 Feedback Categories

The workflow classifies feedback into three categories:

- **Complaint:** Identifies customer problems and negative feedback.
- **Compliment:** Recognizes positive customer experiences.
- **Future Addition Request:** Identifies suggestions and requests for future features.
